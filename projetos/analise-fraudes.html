Análise de Fraudes

Este projeto tem como objetivo demonstrar as principais técnicas de análise de dados utilizando exclusivamente SQL e um banco de dados, explorando consultas, filtros, agregações, cruzamento de informações e identificação de padrões para analisar transações financeiras e detectar possíveis fraudes.

Postgres SQLCSV
Código no GitHub
↳ Análise comentada de mais de 600 mil transações usando apenas SQL (PostgreSQL) para entender o comportamento da fraude. Investiguei padrões por tipo de transação, estado, faixa de valor e movimentação de saldo, além de contas que recebem fraude repetidamente e transações em sequência. Também medi a eficácia da regra de bloqueio atual, comparando o que ela marcou com o que de fato foi fraude.
Visão geral

Sobre o projeto

O problema

O projeto consiste em analisar um conjunto de dados de transações financeiras para identificar padrões de fraude utilizando exclusivamente SQL e um banco de dados PostgreSQL.

A solução

A solução envolveu a criação de consultas SQL comentadas para extrair insights sobre os padrões de fraude identificados.

Meu papel

Conduzi a análise dos dados comentando a lógica por trás da análise segundo a experiência adquirida no decorrer de anos trabalhando com dados financeiros.

Destaques

Principais funcionalidades

Funcionalidade

O projeto visa identificar padrões de fraude em transações financeiras através de uma análise detalhada utilizando SQL e PostgreSQL.

Finalidade

Auxiliar profissionais de segurança na detecção de fraudes em tempo real.

Stack

Tecnologias utilizadas

SQL Python PostgreSQL

Resultado

Construí uma análise exploratória completa de fraude em mais de 600 mil transações, usando apenas SQL (PostgreSQL). O trabalho identificou em quais tipos de transação, estados e faixas de valor a fraude se concentra, os padrões de saldo que a denunciam (como contas esvaziadas) e as contas que recebem fraude repetidamente. Também avaliei a regra de bloqueio atual, medindo quantas fraudes ela deixa escapar. O resultado foi um roteiro de análise documentado e reutilizável, com orientações de interpretação para cada etapa.
